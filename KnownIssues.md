# Known Issues & Feature Backlog

## Known Issues (Reference Speedy vs CombiSpeed)

| ID | Issue Description | Reference (Speedy) Status | CombiSpeed Resolution Status |
|---|---|---|---|
| ISSUE-001 | Speedy SOCKS proxy failed to bind outgoing socket to adapter IP (`net.connect` omitted `localAddress`), resulting in default gateway routing rather than adapter bonding. | Bug in Speedy `socks.ts:63` | **Resolved**: CombiSpeed explicitly binds `{ localAddress: adapter.address }` on every outgoing TCP socket connection. |
| ISSUE-002 | Speedy spawned a new server listener on port 8080 for each incoming client connection inside `socks.ts:78`, resulting in `EADDRINUSE` port conflict and crash under concurrent load. | Bug in Speedy `socks.ts:78` | **Resolved**: CombiSpeed uses a unified direct socket duplex pipe without re-listening on local ports for every request. |
| ISSUE-003 | Speedy only supported SOCKS5 IPv4 and lacked HTTP/HTTPS proxy support, breaking standard Windows system proxy and browser out-of-the-box usage. | Missing in Speedy | **Resolved**: CombiSpeed implements both RFC 1928 SOCKS5 and HTTP/HTTPS CONNECT forward proxy, supporting 100% of Windows applications. |
| ISSUE-004 | Lack of Windows System Proxy automation required cumbersome manual browser configuration. | Missing in Speedy | **Resolved**: CombiSpeed introduces a 1-click Windows System Proxy toggle that configures `Internet Settings` in the Windows registry with automatic revert on exit. |
| ISSUE-005 | No real-time bandwidth speedometer, per-adapter latency pings, or adapter health checks. If an adapter disconnected, requests would hang or fail. | Missing in Speedy | **Resolved**: CombiSpeed integrates continuous per-adapter ICMP/TCP latency pings, health checks with auto-failover, and real-time live throughput telemetry. |
| ISSUE-006 | Single-connection downloads cannot span multiple adapters over standard single-stream TCP unless parallel streams or segmented downloading are utilized. | Inherent to TCP | **Mitigated**: CombiSpeed provides multi-stream parallel socket bonding and a built-in multi-connection speed benchmark tool that exercises all bonded adapters simultaneously. |
| ISSUE-007 | Sudden application crash or termination leaving Windows System Proxy enabled, blocking direct internet. | Risk in System Proxying | **Resolved**: Multi-layered safety net: `CombiSpeed.exe --stop` IPC signal, WinINet option refresh, and registry fallback in `Stop-CombiSpeed.bat` ensure direct internet is always restored. |
| ISSUE-008 | Complicated manual installation or requirement for elevated UAC admin rights. | Deployment friction | **Resolved**: `Install-CombiSpeed.bat` deploys cleanly to `%LOCALAPPDATA%\Programs\CombiSpeed` without UAC prompts, auto-creates Desktop/Start Menu shortcuts, and integrates into Windows Apps & Features. |
| ISSUE-009 | Proxy-only solutions require application-level proxy awareness and cannot bond system-wide traffic through a dedicated Windows network interface connection. | Speedy had no virtual adapter or VPN | **Resolved**: CombiSpeed v1.2.0 introduces the **Virtual Bonded Bridge & Adapter Connection** (`CombiSpeed Bonded Bridge`), creating a native Windows network connection in `ncpa.cpl` and Windows Settings that merges active physical adapters and multiplexes bandwidth based on the exact % set for each connection via Smooth Weighted Round Robin. |
| ISSUE-010 | Adapter selections, customized percentage ratios, and combination profiles lost on restart or rescan. | Speedy had no persistence | **Resolved**: CombiSpeed v1.3.1 implements durable configuration persistence in `%LOCALAPPDATA%\CombiSpeed\adapter_settings.json` with debounced auto-save, MAC address binding, and combination profiles. |
| ISSUE-011 | Connection-based round-robin multiplexing did not throttle actual byte transfer speeds or enforce bandwidth limits across combined adapters. | Speedy had no throttling or rate limiting | **Resolved**: CombiSpeed v1.3.2 implements high-performance asynchronous Token Bucket `BandwidthThrottler` across all TCP, UDP, and Virtual Bridge streams, enforcing strict proportional speed shaping and configurable bandwidth caps. |
| ISSUE-012 | Static bandwidth shaper rate limiting did not adapt to real-time ping spikes or bufferbloat, and lacked optimization modes for maximum bandwidth vs lowest gaming latency. | Missing in Speedy & prior versions | **Resolved**: CombiSpeed v1.3.6 implements Dynamic Cross-Connection Speed Shaping with selectable `MaximumBandwidth`, `LowestLatency`, and `BalancedDynamic` modes, real-time live ping feedback adaptation, anti-bufferbloat burst pacing (20ms), dynamic capacity borrowing, and latency-weighted SWRR dispatching. |
| ISSUE-013 | UI vertical scrolling fatigue on low-resolution displays and lack of WCAG 2.1 AA accessibility (high contrast themes, dynamic UI scaling, screen reader labels, keyboard shortcuts). Initial tab redesign encountered stacking collision due to custom visibility bindings. | Missing in Speedy & prior versions | **Resolved**: CombiSpeed v1.4.0 introduces Modern Segmented Tabbed Navigation using native WPF `TabControl` (`⚡ Overview & Dashboard`, `🖧 Combined Adapters`, `🚀 Speed Shaper & QoS`, `📜 Connection Audit`), 100% reliable tab switching, full WCAG 2.1 AA compliance (High Contrast `#030712`/`#38BDF8`, Dynamic UI Scaling 100%-130%, Reduce Motion mode, Screen Reader `AutomationProperties`, and global hotkeys `Space`, `Alt+P/B/W/R/A/S/H`, `Ctrl+1-4`). |
| ISSUE-014 | Standard Windows WPF Aero2 `ComboBox` rendered with light OS toggle button causing white-on-white text, popup lack of dark styling, and low-contrast muted labels (`#94A3B8`, `#334155`) causing text to be unreadable across the application. | Missing in Speedy & prior versions | **Resolved**: CombiSpeed v1.4.1 implements a custom accessible dark `ComboBox` ControlTemplate (`#131D33` button, `#00F0FF` chevron, `#0B1120` popup, `#FFFFFF` high-contrast text), global anti-fallback styles for `TextBlock` and `Label`, high-contrast dark `DataGrid` styling, and upgraded all text labels to high-contrast colors (`#FFFFFF`, `#38BDF8`, `#F1F5F9`, `#CBD5E1`) achieving 14:1+ contrast ratios. |
| ISSUE-015 | Lack of direct PAC file saving/exporting to disk for external browser or operating system configuration without manual copy-paste. | Missing in Speedy & prior versions | **Resolved**: CombiSpeed v2.0.0 introduces direct PAC file exporting via a **"💾 Export PAC File..."** button in Settings, `SaveFileDialog` with `.pac` and `.js` support, and a cross-platform `--export-pac [path]` CLI flag. |
| ISSUE-016 | Application was restricted to Windows only, preventing Linux and macOS users from bonding multiple network adapters and enjoying dynamic speed shaping. | Speedy was Electron-only prototype | **Resolved**: CombiSpeed v2.0.0 creates dedicated, separate native codebases for **Linux (`CombiSpeed-Linux/`)** and **macOS (`CombiSpeed-macOS/`)**, featuring low-level socket routing (`SO_BINDTODEVICE` on Linux, `IP_BOUND_IF` on macOS), native system proxy managers, separate multi-OS distribution publishing, and 100% identical cyberpunk glassmorphic UI/UX and feature parity. |
| ISSUE-017 | Speed benchmark froze or hung indefinitely on virtual host-only adapters (such as Hyper-V `vEthernet` or WSL bridges with unroutable IPs `172.19.96.1` / `172.31.0.1`), and failed with `10049 WSAEADDRNOTAVAIL` when system proxy was active due to loopback routing conflicts. | Inherent to unroutable adapters | **Resolved**: CombiSpeed v2.0.1 introduces 1500ms pre-flight latency probing (auto-skipping dead/unroutable adapters), proxy bypass isolation (`SocketsHttpHandler.UseProxy = false`), strict IPv4 DNS resolution, multi-stream bonded socket throughput, and cross-platform native benchmark parity on Linux (`LinuxSpeedTester.cs`) and macOS (`MacSpeedTester.cs`). |
| ISSUE-018 | Bandwidth was split across connections into fractional slices (e.g. 50% or 25% per adapter) under proportional rate limiting, preventing connections from achieving full combined speed, and single-connection downloads ran over only one adapter at a time. | Inherent to proportional slicing | **Resolved**: CombiSpeed v2.0.2 introduces Combine Speeds Mode (pooling aggregate bandwidth additively without splitting per-adapter slices) and a Multi-NIC Parallel Range Chunk Speed Combiner in ProxyEngine.cs, allowing single file downloads to stream across all active adapters concurrently. |
| ISSUE-019 | Standard rotating proxy tools route through a single default gateway, causing local router bottlenecking and inability to scrape or rotate proxies from open-source feeds directly within a multi-WAN pipeline. | Missing in standard tools | **Resolved**: CombiSpeed v2.1.0 introduces an Automated Rotating Proxy Harvester & Multi-NIC Egress Dispatcher (port 8081), scraping candidate proxies from open-source feeds/URLs, validating health/anonymity in parallel, and binding outbound connections across local physical adapters for double-layer multi-WAN acceleration. |
| ISSUE-020 | Rotating proxy pools quickly degraded over time without manual harvesting/validation, lacked regional GeoIP country filtering, and could not authenticate against private upstream proxies requiring username/password. | Missing in standard scraping tools | **Resolved**: CombiSpeed v2.1.1 introduces an Autonomous Background Scheduler (30m harvest, 5m validate & dead-pruning), GeoIP Country Filtering with graceful fallback, JSON API scraper parsing, and full upstream authentication support (HTTP Basic & RFC 1929 SOCKS5). |

- [x] PAC (Proxy Auto-Config) rule generator for domain-based interface routing.
- [x] Windows service mode for background headless execution without GUI.
- [x] UDP associate relay support for SOCKS5 (gaming/streaming UDP acceleration).
- [x] Adapter settings and combination profile persistence with debounced auto-save and startup restoration.
- [x] Real-time bandwidth throttling & speed shaper enforcing proportional bandwidth and speed caps across combined connection adapters.
- [x] Application version display in main window titlebar badge, glassmorphic footer status bar, and --version CLI flag.

- [x] Redesigned modern Segmented Tabbed Navigation (⚡ Overview & Dashboard, 🖧 Combined Adapters, 🚀 Speed Shaper & QoS, 📜 Connection Audit) with native WPF TabControl.
